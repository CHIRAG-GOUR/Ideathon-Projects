# Smart LPG Cylinder Safety Dock — *Smart. Safe. Secure.*

**CONCEPT / PROTOTYPE.** An interactive simulator of a smart dock that sits under an LPG cylinder, watches gas, temperature,
tilt and usage, warns the cook, and (in the simulation) shuts off the supply. **Every reading, warning, shutoff and incident
is simulated** by an illustrative model. This software does not detect real gas, does not control a real valve, and makes no
claim of certified safety performance.

| | |
|---|---|
| **Web app** | React + TypeScript + Three.js (react-three-fiber) — `web/` → Firebase Hosting |
| **Android app** | Native Java (no WebView), OpenGL ES 2.0 3D — `mobile/` → `com.skillizee.lpgdock` 1.0.0 (APK + AAB) |
| **Engine** | One deterministic simulation (`shared/src/engine.ts`) with a Java port verified step-for-step against it |
| **Backend** | Firebase Auth (optional) + Firestore, dedicated project, owner-only rules — `firebase/` |

## What it shows

Two runs of the same restaurant kitchen, the same chef and the same leak:

- **Without the dock** — gas rises 0.04 → 0.12 → 0.28 → 0.51 → 0.83 ppm with nobody measuring it. The chef only notices at
  DANGER and gets out; then a clearly labelled **SIMULATED INCIDENT — FOR DEMONSTRATION ONLY** (flash, shake, fire/smoke,
  sound), then the scene freezes for recovery.
- **With the Smart Dock** — the anomaly is detected, NORMAL → WARNING with an alarm, **SIMULATED AUTOMATIC SHUTOFF**,
  **LPG SUPPLY ISOLATED**, the chef turns off the burner, walks out calmly and does a "whew". **INCIDENT CONTAINED** —
  Gas 0.04 ppm · Temp 25.4 °C · Tilt 0.4° · Dock SAFE · Cylinder ISOLATED. **No simulated blast occurred.**

State machines (generated by the engine, never hand-animated):

- with dock: `IDLE → COOKING → ANOMALY → WARNING → CRITICAL → RESPONSE → CONTAINED`
- without: `IDLE → COOKING → LEAK → DANGER → SIMULATED INCIDENT → RECOVERY`

Screens (web sidebar / bottom nav on phones; Android bottom nav + "More", side rail on tablets):
**Dashboard · Simulation · Compare · Smart Dock (3D product, clickable parts, exploded view) · Telemetry · Events ·
Presentation (10 chapters with RUN LIVE DEMO) · Settings**. Start / Pause / Restart, 0.5× / 1× / 2×, and
**SIMULATION CONTROLS** to inject a gas leak, temperature rise, cylinder tilt or unusual usage at any time.

## Quick start

```bash
npm --prefix shared ci && npm --prefix web ci
npm --prefix web run dev                 # http://localhost:5173 — works fully offline, no Firebase needed
npm test                                 # engine tests
bash mobile/build.sh                     # Android APK + AAB → mobile/build/
```

## Honesty rules this project follows

- Everything simulated is labelled SIMULATED or CONCEPT / PROTOTYPE, on every screen that shows a value.
- The incident is an *educational visualisation* and is labelled as such while it plays.
- Numbers on the presentation's "why early detection matters" chapter are computed live from the engine and its config,
  with a note that they are illustrative, not measured.
- Firebase is optional. Without it the apps say "not configured" — they never fake a successful save.
- Colour is never the only signal (symbols + words), and sound is never the only signal (on-screen text for every cue).
